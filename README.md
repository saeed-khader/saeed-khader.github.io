# Saeed Khader Alzahrani — Portfolio

Personal portfolio website — IT support, networking, and technical services.

**Live site:** https://shlvvn.github.io/saeed-portfolio/

## Stack

- React + TypeScript
- TanStack Start / TanStack Router
- Tailwind CSS
- Vite

## Local development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Deployment to GitHub Pages runs automatically via GitHub Actions on every push to `main`.
